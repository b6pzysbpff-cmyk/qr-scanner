MEIN CODE-SCANNER – VERSION 3 (QR + EAN / BARCODES)

Unterstützt QR-Code, EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39 und ITF.
Bibliothek: ZXing (MIT-Lizenz), geladen via jsDelivr; beim ersten Aufruf wird Internetzugang benötigt.
Scans und Kamerabilder werden nicht an einen Server versendet.

UPDATE AUF DEM BESTEHENDEN GITHUB-REPOSITORY
1. Auf github.com anmelden.
2. Repository qr-scanner öffnen.
3. Add file > Upload files.
4. Die Dateien index.html, manifest.webmanifest, sw.js und ANLEITUNG.txt aus diesem entpackten Ordner wählen und hochladen.
   Der vorhandene Ordner icons/ kann unverändert bleiben.
5. Commit changes bestätigen.
6. GitHub Actions / Pages prüfen, ob der neue Stand veröffentlicht wurde.
7. Auf iPhone in Safari und auf Samsung in Chrome die bestehende Webseite neu laden.
   Bei alten PWA-Versionen gegebenenfalls die installierte App entfernen und neu hinzufügen.

Hinweis: Manche sehr kleinen oder beschädigten Barcodes lassen sich mit der Smartphone-Kamera nur schwer lesen.
Barcode-Nummern identifizieren nicht automatisch Produktnamen; dafür wäre eine externe Produktdatenbank nötig.
